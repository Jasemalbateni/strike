# STRIKE — بوابة الفريق

البوابة الداخلية لفريق أكاديمية سترايك. للموظفين المصرّح لهم فقط.

**الوحدة الأولى: مركز التسويق** — الأهداف، خطة التسويق، العصف الذهني، تقويم المحتوى (شهر/أسبوع)، سير العمل (Kanban)، تعليقات وإشارات @ على المنشورات، ومتابعة الأرقام. كل تغيير يظهر للكل باللحظة (Supabase Realtime + Presence).

## التقنيات

- Next.js 16 (App Router) + TypeScript + Tailwind v4
- Supabase (Auth + Postgres + Realtime) — مشروع `Strike Platform`
- `@dnd-kit` للسحب والإفلات

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # ثم ضع مفتاح Supabase الـ publishable
npm run dev
```

المتغيرات المطلوبة:

| المتغير | الوصف |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | رابط مشروع Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | المفتاح العام (publishable / anon) |

لا يحتاج المشروع مفتاح service role: إدارة الحسابات تتم عبر دوال SQL محمية (المالك فقط).

## النشر على Vercel

1. Import الريبو في Vercel.
2. أضف المتغيرين أعلاه في Environment Variables.
3. Deploy. أضف رابط النشر في Supabase → Authentication → URL Configuration (Site URL).

## الحسابات والصلاحيات

- تسجيل الدخول باسم مستخدم وكلمة مرور فقط (لا تسجيل ذاتي).
- المالك ينشئ الحسابات من صفحة **الفريق** ويحدد الدور (مالك / مدير فرع / إداري / مدرب) و**الصفحات اللي تظهر لكل موظف**: الحضور، اللاعبين، رسم التمارين، التقويم، مركز التسويق (المالك يشوف كل شي).
- الصفحات محمية مرتين: القائمة تخفيها، و RLS في قاعدة البيانات يمنع البيانات (`profiles.access` + `has_access()`).
- اعتماد التمارين للمكتبة: المالك أو مدير الفرع (`can_approve_drills()`).
- لا أحد يرى دور أو صلاحيات غيره؛ صفحة الفريق للمالك فقط.
- تغيير كلمة المرور من **الإعدادات**.

## قاعدة البيانات (Supabase)

الجداول: `profiles`, `mk_goals`, `mk_plan_items`, `mk_ideas`, `mk_posts`, `mk_comments`, `mk_metrics`, `mk_activity`.
كل جداول `mk_*` محمية بـ RLS: يقرأها ويعدلها فقط من لديه `marketing_access` (والمالك دائماً).
سجل النشاط `mk_activity` يُملأ تلقائياً بـ triggers.

الدوال الإدارية (المالك فقط): `admin_create_user`, `admin_set_password`, `admin_delete_user`.

### اللاعبين والحضور

الجداول: `branches` (الفروع وأيام التدريب وإيجار الملعب)، `groups` (الفئات)، `players`، `subscriptions`، `sessions` (حصة لكل فرع/تاريخ)، `attendance`.

- **الحضور** (`/attendance`) لكل الموظفين: يفتح الحصة تلقائياً مع أول علامة، ضغطة على الاسم = حاضر / غائب، أزرار صغيرة لـ «متأخر» و«غياب بعذر»، زر «تجربة» يضيف لاعب تجربة ويحضّره فوراً (يظهر باللون الذهبي).
- **اللاعبين** (`/players`) للمالك ومدير الفرع والإداري فقط (`can_manage_players()`): بيانات ولي الأمر، الاشتراكات، تنبيهات «منتهي» و«ينتهي خلال ٧ أيام»، قمع التجارب (سجّلوا ← حضروا ← اشتركوا) وتكلفة التسويق لكل مشترك جديد (إنفاق `mk_metrics.spend` ÷ التجارب المحوّلة).
- المدربون لا يرون الاشتراكات ولا بيانات ولي الأمر (RLS + حذف الحقول في الخادم).
- نهاية الاشتراك تُحسب من عدد الحصص وأيام تدريب الفرع (`nth_session_date` في SQL و`nthSessionDate` في `lib/players.ts`).
- إحصاءات: view `player_attendance_stats` (حضور/غياب لكل لاعب) ودالة `period_stats(from, to)` (حصص، حضور، إيجار الملعب، إيراد الاشتراكات، إنفاق التسويق).

### التمارين (لوحة الرسم) والتقويم

- **التمارين** (`/drills`): مكتبة (المعتمد)، بانتظار الاعتماد، مسوداتي. التمرين الجديد `/drills/new`، والتمرين `/drills/[id]`.
- اللوحة (`components/drills/editor.tsx`): SVG بإحداثيات ثابتة (10 وحدات = 1 متر). ملعب كامل/نصف/منطقة جزاء/مصغّر/بدون خطوط، أفقي أو عمودي، ألوان الأرضية والخطوط.
  عناصر STRIKE من ملفات Illustrator (`Drawing Elements` → `lib/drills/art.ts`، كل عنصر بلونين قابلين للتغيير) + شاخص، حاجز، حلقة، علم، دمية.
  خطوط مستقيمة/منحنية/زقزاق/موجة، متصلة/متقطعة/منقطة، بسهم أو سهمين أو بدون، تلتصق باللاعب. أشكال (مربع/دائرة/مثلث) بإطار وتعبئة وشفافية. نص، قلم حر.
  تحديد متعدد (سحب مربع / Shift / زر التحديد المتعدد باللمس)، محاذاة ذكية، محاذاة وتوزيع، قفل، تكرار، نسخ/لصق، تراجع/إعادة، تكبير بإصبعين، **سحب العنصر خارج الملعب = حذف**.
  مراحل (Frames) مع تشغيل متحرك بين المراحل، وتصدير صورة PNG بهوية STRIKE.
- الجداول: `drills` (الحالة: `draft` → `pending` → `approved` أو `returned` مع ملاحظة)، `plan_items` (تمارين وأحداث لكل يوم/فرع/فئة).
- **التقويم** (`/calendar`): أيام التدريب من `branches.training_days`، خطة الحصة (مجموع الدقائق مقابل `branches.session_minutes`)، أحداث/مباريات/إجازات/ملاحظات، وعدد الحضور للأيام الماضية.

## هيكل الكود

```
src/
  proxy.ts                     # تجديد الجلسة + حماية الصفحات
  lib/supabase/{client,server} # عملاء Supabase
  lib/auth.ts                  # getProfile / hasAccess / canApproveDrills / canManagePlayers
  lib/types.ts                 # الأنواع والتسميات العربية
  lib/players.ts               # أنواع اللاعبين + حساب نهاية الاشتراك وحالته
  lib/drills/                  # نموذج اللوحة، الهندسة (أسهم/زقزاق)، الملاعب، عناصر الرسم
  components/drills/           # لوحة الرسم (editor)، الألوان والأدوات، التصدير، صفحة التمرين (studio)
  app/login                    # تسجيل الدخول
  app/(portal)/                # الصفحات المحمية: الرئيسية، attendance، players، drills، calendar، marketing، team، settings
  components/shell.tsx         # القائمة الجانبية / السفلية
  components/marketing/        # مركز التسويق: store (realtime) + التبويبات
```
